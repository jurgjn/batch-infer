# /cluster/project/beltrao/shared
- AlphaFold 3 data pipeline (MSA + templates) pre-computed for human/yeast; sequences taken from [AFDB_v4](https://ftp.ebi.ac.uk/pub/databases/alphafold/v4/); both directories contain [a pre-generated data-fill index](https://github.com/jurgjn/af3io)
    - `25.05_alphafold3_msas_human/` 70G gzip-compressed
    - `25.06_alphafold3_msas_yeast/` 18G gzip-compressed
- `alphafold3/images` containers for [AlphaFold 3 (different versions)](https://hub.docker.com/r/jurgjn/alphafold3) and similar co-folding tools
